# 跨資產投資模擬器

以互動儀表板比較台股 ETF、美股 ETF、比特幣和黃金 ETF 的歷史投資結果，並展示 Random Forest 與 Ridge 的未來報酬情境。這是教育用途的專題原型，不是投資建議，也不保證模型能預測市場。

## 功能

- 比較 0050.TW、SPY、BTC-USD 和 GLD。
- 將海外資產價格依 USD/TWD 換算為新台幣。
- 回測一次投入，或把固定總預算平均分配到每月投入。
- 顯示期末資產價值、損益、年化現金流報酬、年化波動和標的最大回撤。
- 以時間順序驗證在 Random Forest 和 Ridge 之間選模，並用保留測試資料和零報酬、訓練期平均報酬基準比較誤差。
- 顯示模型中央估算和測試期報酬分位數情境。

每個標的都以**單獨投入全部預算**計算。多標的畫面是平行比較，不是混合資產的投資組合。

## 安裝與啟動

需要 Python 3.10 以上和網路連線。在 PowerShell 執行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

如 PowerShell 阻止啟用虛擬環境，可直接使用虛擬環境內的 Python：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## 計算方式

### 市場資料

程式透過 `yfinance` 下載 Yahoo Finance 調整後收盤價和 USD/TWD 匯率。外幣資產依資產本身的有效交易日換算。資產價格不會用前一日價格補上週末或休市日，避免把重複報價當成零報酬觀測。

### 歷史回測

- **一次投入：**期間起點投入全部預算。
- **定期定額：**將同一筆總預算平均分到每月第一個有效交易日。
- **年化報酬：**以實際投入日期和期末資產價值計算 XIRR。
- **波動度：**使用有效觀測日的報酬標準差年化；ETF 按每年 252 個交易日，比特幣按每年 365 個日曆日計算。
- **最大回撤：**根據標的報酬指數計算，避免後續投入金額把帳戶價值抬高而低估回撤。

### 模型估算

`model.py` 以價格建立 5、20、60 期動能、20、60 期波動度，以及價格相對移動平均線的差距，預測未來 H 個有效價格觀測的對數報酬。波動度特徵依資產頻率年化：ETF 使用 252，比特幣使用 365。

資料依時間分成前 80% 開發區和後 20% 保留測試區。開發區內再做時間順序驗證來選擇 Random Forest 或 Ridge；切分邊界保留 H 筆資料，降低前向報酬標籤跨界重疊。保留測試區用於報告 MAE、RMSE，並與零報酬和訓練期平均報酬基準比較。

測試區實際報酬的第 10 與第 90 百分位數作為歷史情境範圍。它不是統計信賴區間，也不是未來結果的保證。每日起點的 H 期報酬標籤彼此可能重疊，因此測試誤差存在時間相依性，應作描述性參考。

## 使用限制

- Yahoo Finance 資料可能缺漏、延遲或修訂；海外資產匯率換算以可取得的匯率觀測為準。
- 回測和模型尚未計入交易手續費、稅負、滑價、ETF 配息稅務或匯兌成本。
- 模型沒有證明能持續勝過簡單基準。金融市場的分布會改變，過去誤差不代表未來表現。
- 模型期末估算假設目前把全部預算一次投入單一標的，即使歷史回測選擇定期定額也一樣。
- 本工具供教育和方法比較使用，不提供個人化投資建議。
